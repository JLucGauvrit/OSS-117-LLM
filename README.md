# OSS 117 LLM 🚀🕵️‍♂️

![OSS 117](images/oss%20117.jpg)

OSS 117 LLM est un projet open-source qui vise à créer un LLM (Large Language Model) from scratch, inspiré par l’humour et le caractère unique du célèbre agent OSS 117. 

Ce projet a surtout pour but de vous faire progresser sur toutes les étapes de création, d’entraînement et d’orchestration d’un modèle de langage. 

## Objectifs du projet 🎯

- Créer un dataset original et complet, fidèle à l’univers OSS 117. 📚
- Développer les scripts de préparation des données et d’entraînement du modèle LLM (from scratch). 🛠️
- Construire une interface de supervision (UI) pour suivre l’entraînement du modèle. 📊
- Mettre en place l’inférence : utilisation du modèle pour générer des textes à la OSS 117. 🤖

## Fonctionnalités principales prévues 📝

- Collecte, nettoyage et structuration du dataset. 🧹
- Module d’entraînement du LLM (Python, gestion avec Docker Compose). 🐍🐳
- Interface de suivi (web ou desktop) pour monitorer en temps réel les métriques d’entraînement. 🖥️
- Script ou API d’inférence. 🗣️

## Installation ⚙️

Cloner le dépôt et lancer l’environnement Docker Compose :

```bash
git clone https://github.com/JLucGauvrit/OSS-117-LLM
cd OSS-117-LLM
docker compose up --build
```
